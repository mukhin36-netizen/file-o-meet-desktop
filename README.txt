FILE-O MEETING · Настольное приложение 0.6.0
Windows x64 · macOS Apple Silicon (M1–M5) · macOS Intel

ПРЕДВАРИТЕЛЬНАЯ ТЕСТОВАЯ СБОРКА
Приложение готово к установке и использует действующие API FILE-O.
До полноценного релиза необходимо проверить захват системного аудио
на реальном компьютере с Windows и на конкретном Mac.

НОВЫЙ ДИЗАЙН И РАБОТА С ПРОТОКОЛАМИ
- Разделы «Главная», «Все встречи», «Новая запись», «Документы»,
  «Настройки» в едином рабочем пространстве.
- История и состояния встреч загружаются из вашего аккаунта FILE-O.
- Готовый протокол можно открыть в приложении: расшифровка с
  таймкодами, краткие тезисы, решения, задачи, важные моменты.
- Текст протокола, название, количество участников и поручения
  сохраняются на сервере с проверкой версии документа.
- Экспорт DOCX, TXT, ZIP и SRT выполняется через единый кабинет FILE-O.
- Говорящие пока автоматически не идентифицируются, аудиоплеер
  отсутствует: исходные аудиофрагменты удаляются после обработки.

ЧТО ДЕЛАЕТ
- По нажатию записывает системный звук с компьютера: Яндекс Телемост,
  Zoom, другие программы и браузер (с разрешения ОС).
- По отдельному разрешению добавляет ваш микрофон.
- Передаёт самостоятельные аудиофрагменты в FILE-O каждые ~25 секунд.
- Постепенно показывает распознанные слова в приложении.
- Кнопка «Выделить важный момент»: первый клик добавляет 20 секунд до
  нажатия; второй завершает выделение.
- После звонка сохраняет протокол с решениями, задачами и рисками,
  полную расшифровку и конспект в личном кабинете FILE-O.
- Работает при закрытом (скрытом в трей) окне приложения. Полностью
  завершать процесс во время записи нельзя.
- Если пропал интернет, зашифрованные фрагменты временно сохраняются
  локально и при восстановлении связи отправляются повторно.
- При перезапуске НЕ включает микрофон и запись самостоятельно.

СИСТЕМНЫЙ ЗВУК
При выборе «Звук компьютера» запись может содержать не только звонок,
но и звуки других запущенных программ, уведомлений и вкладок.
Для исключения посторонних звуков отключите ненужные программы/уведомления.
Приложение не получает данные из внутреннего API Телемоста.
Изображение экрана НЕ записывается в файл, только аудио.

WINDOWS
1. Скачайте архив FILE-O-Meeting-Windows-x64.zip.
2. Распакуйте ВСЮ папку на диск. Не переносите exe отдельно.
3. Запустите FILE-O-Meeting.exe.
4. Это тестовый EXE БЕЗ цифровой подписи. Windows SmartScreen может
   предупредить об неизвестном издателе. Не запускайте файлы из
   непроверенных источников.
5. Для захвата системного звука может потребоваться разрешить
   запись экрана и звука в диалоге Windows.
6. Для собственного голоса разрешите доступ к микрофону.

MACOS
1. Уточните процессор: Меню Apple → Об этом Mac.
   M1/M2/M3/M4/M5 — Apple Silicon; старые модели — Intel.
2. Скачайте архив своей архитектуры.
3. Распакуйте FILE-O-Meeting.app и переместите в Программы.
4. Требуется macOS 14.2 или новее.
5. Сборка НЕ подписана Apple и не нотариализована. macOS Gatekeeper
   может запретить запуск. В системных настройках macOS проверяйте
   издателя и разрешайте запуск только доверенных приложений.
6. Для записи системного звука выберите источник в системном
   диалоге macOS. Предоставьте разрешение System Audio Recording,
   при необходимости также Screen Recording.
7. Для микрофона отдельно разрешите его использование.
8. Если macOS предоставила «мёртвую» аудиодорожку, приложение
   предупредит вас и не создаст фиктивный протокол звонка.
9. Неподписанная сборка на macOS ещё не испытана на настоящем Mac;
   для массового выпуска потребуется подпись и нотариализация.

ПОДКЛЮЧЕНИЕ FILE-O
1. Откройте https://file-o.com/meeting и авторизуйтесь.
2. Создайте одноразовый код (действует 10 минут).
3. Введите его в приложении FILE-O Meeting.
4. Для записи встречи нужен тариф «Плюс навсегда».
   По отдельному разрешению тестового аккаунта также доступна
   демонстрация без изменения оплаченной подписки.
5. Введите название встречи и число участников, если известно.
6. Уведомите всех участников о записи и получите необходимые
   разрешения. Подтвердите это галочкой.
7. Выберите «Звук компьютера», «Мой микрофон» или оба источника.
8. Нажмите «Начать запись».
9. По необходимости отмечайте важные моменты.
10. Нажмите «Завершить встречу» и дождитесь передачи данных.
11. Посмотреть документы:
    https://file-o.com/account?section=telemost

ВАЖНО ПРО ДАННЫЕ
- Участники не записываются без вашего нажатия.
- Не записывайте чужие переговоры без разрешения.
- По окончании обрабатываемые фрагменты удаляются с сервера;
  протоколы в личном кабинете сохраняются до удаления владельцем.
- Локальные ожидающие передачи аудиофрагменты шифруются AES-256-GCM,
  ключ защищён системным хранилищем Windows/macOS.
- Если система не предоставляет безопасное хранилище, приложение
  откажет в начале новой записи, чтобы не сохранять аудио без защиты.
- Отключите системный звук, если хотите записывать только свой микрофон.
- Перепроверяйте числа, имена и решения по оригиналу речи.

ЭТО НЕ ИНСТАЛЛЯТОР
Windows: готовое портативное приложение EXE с зависимостями в ZIP.
macOS: готовый неподписанный пакет .app в ZIP.
Для публичного магазина понадобятся подпись и дополнительные тесты.
