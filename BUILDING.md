# FILE-O Meeting Desktop · сборка и архитектура

Это тестовая настольная программа на **Electron 45.3.2** для Windows и macOS.
Она использует защищённое API существующего сервиса FILE-O; здесь нет ключей
распознавания, платёжных ключей и паролей от сервера.

## Локальная разработка

Необходим Node.js 22+ и npm 10+.

```bash
npm ci
npm test
npm start
```

Чтобы программа подключилась к личному кабинету, откройте
https://file-o.com/meeting, создайте одноразовый код и введите его в приложении.

## Сборка тестовых приложений

Windows (64-bit, portable directory с EXE):

```bash
npx electron-packager . FILE-O-Meeting --platform=win32 --arch=x64 \
  --out=dist --overwrite --icon=assets/fileo.ico --asar \
  --prune=true --ignore='^/dist' --ignore='^/tests'
```

macOS (лучше собирать и подписывать **на Mac**):

```bash
node pack-mac.cjs arm64
node pack-mac.cjs x64
```

Команда `pack-mac.cjs` добавляет ключи
`NSAudioCaptureUsageDescription` и `NSMicrophoneUsageDescription` в Info.plist.
Производственный релиз необходимо подписать, включить Hardened Runtime и
нотариализовать Apple, затем проверить через `codesign` / `spctl` на macOS.

Тестовые архивы .app сформированы на Linux и **не имеют цифровой подписи**.
Запуск на macOS зависит от Gatekeeper, OS-аудиоразрешений и код-подписи.

## Как идёт запись

1. Пользователь открывает локальную страницу приложения (HTML/CSS/JS)
   в sandboxed BrowserWindow. Node.js в неё не внедрён.
2. Renderer вызывает `getDisplayMedia({video:true,audio:true})` непосредственно
   по нажатию пользователя. Electron на macOS использует **нативный системный
   выбор источника** для CoreAudio Tap; Windows — loopback звука экрана.
3. Из захваченного потока берётся **только audio**; видеокадры не записываются.
4. По отдельному разрешению подключается микрофон, оба потока смешиваются
   через Web Audio API.
5. `MediaRecorder` создаёт отдельный самодостаточный WebM/Opus или MP4/AAC
   фрагмент каждые 25 секунд; не используем timeSlice, который выдаёт
   неполные контейнеры.
6. Blob передаётся в IPC, главный процесс шифрует AES-256-GCM и сохраняет
   на диск до подтверждения загрузки. Ключ AES хранится зашифрованным
   через Electron safeStorage (Keychain / DPAPI).
7. Главный процесс последовательно передаёт фрагменты по HTTPS на
   `/api/meeting/sessions/{id}/chunks/{sequence}`, с исходной временной
   меткой. После HTTP 202 локальный фрагмент удаляется.
8. При пропадании сети приложение повторяет отправку; при перезапуске
   пытается восстановить ожидающие файлы **без самопроизвольного запуска
   микрофона или записи**.
9. После остановки приложение ждёт надёжного сохранения последнего
   фрагмента и передаёт `/finish`. На сервере начинается конспектирование.
10. Результаты доступны в личном кабинете. Пометки важных моментов
    сохраняются отдельными интервалами на сервере и анализируются после звонка.

## Что нельзя обещать без проверки на устройствах

- Реальный системный звук зависит от разрешений Windows/macOS.
- На macOS 14.2+ нативный системный пикер обязателен: при выборе экрана
  через собственный picker Chromium иногда возвращает `ended`-аудиодорожку.
  Приложение проверяет `readyState`, чтобы не делать вид, что звук записан.
- Приложение не фильтрует звук строго по процессу Телемоста: loopback
  может содержать и другие уведомления/приложения.
- Код не заменяет подписанные инсталляторы `.exe`/`.dmg`.
- В случае полного выключения компьютера незаконченный MediaRecorder
  фрагмент может быть потерян. Ранее сохранённые файлы остаются в
  зашифрованной локальной очереди.
- Уведомляйте участников и получите необходимые разрешения на запись.

## Безопасность

- `nodeIntegration:false`, `contextIsolation:true`, `sandbox:true`.
- Контент локальный, Content Security Policy запрещает любые renderer-сети.
- Доступ к FILE-O через IPC с явно разрешёнными методами API.
- One-time code → ограниченный токен встречи в safeStorage, без передачи
  пароля от пользователя приложению.
- Системный звук и микрофон — только по действию пользователя.
- Из окна разрешено открыть только проверенные адреса самого FILE-O.
- Запись продолжает работать при скрытии окна, показывается значок в трее.
- Внешние документы и слова из транскрибации отображаются как текст.

## Правки сайта / server API

Серверные модули FILE-O:
`meeting_live_api.py`, `meeting_live_store.py`,
`meeting_live_worker.py`, `meeting_cabinet_api.py`.
Действующая авторизация проверяется для каждого запроса, и специальный
доступ к Телемосту не изменяет покупку тарифа или состояние платежей.
