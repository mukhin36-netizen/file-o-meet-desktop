# Contributing to FILE-O Meet

We welcome bug reports and code contributions to the **desktop client**.

- Check existing GitHub issues before filing a duplicate.
- Reproduce issues with synthetic data; do not upload private meetings,
  emails, tokens, bank information, or customer files.
- Run `npm ci && npm test` and describe your Windows/macOS environment.
- Open a pull request with a clear scope and test evidence.
- Changes to security, recording permissions, API endpoints and build
  pipelines require repository owner review.
- Release artifacts are generated only from approved repository workflows.
- External contributors do not receive code-signing approval privileges.
- Keep license notices in redistributed code and assets.
- Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

The FILE-O server-side recognition and billing service are not part of this
open-source repository.
